#  IPL Season Insights Dashboard (2021–2025)

An interactive data analysis and visualization project covering 5 seasons of the Indian Premier League (2021–2025), built using **Python (Pandas, NumPy, Matplotlib)** and originally modeled after a Power BI dashboard.

## 📊 Overview

This project analyzes IPL match data, team performance, and player statistics across 5 seasons, generating insights such as:
- Season-wise Champions, Runner-ups, and Final venues
- Orange Cap (Top Run Scorer) and Purple Cap (Top Wicket Taker) trends
- Team Points Tables and Win/Loss records
- Fifties vs Hundreds distribution
- Year-wise dynamic filtering

# How to Run
1. Clone this repository
```bash
   git clone https://github.com/TejShah804/IPL-Dashboard-2021-2025-.git
```
2. Navigate into the project folder
```bash
   cd IPL-Dashboard-2021-2025-
```
3. Install dependencies
```bash
   pip install pandas numpy matplotlib openpyxl
```
4. Open `analysis.ipynb` in VS Code or Jupyter Notebook
5. Run all cells to regenerate the dashboard visuals

# Data Source

Data sourced from [Kaggle](https://www.kaggle.com/) — IPL 2021–2025 dataset, covering match results, player statistics, and team performance across all 5 seasons.
